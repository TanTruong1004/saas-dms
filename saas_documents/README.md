# Saas Documents - Hướng Dẫn Sử Dụng

## Bước 1: Cài Đặt Module

Đầu tiên, cài đặt module **Saas Documents** để sử dụng tính năng lưu trữ và quản lý tài liệu trên Dropbox.

---

## Bước 2: Cấu Hình Sử Dụng Dropbox

1. Truy cập vào **Tài liệu -> Cấu hình -> Cấu hình sử dụng Dropbox** để thiết lập thông tin kết nối với Dropbox.
2. Cung cấp các thông tin sau:
    - **Tên tài khoản**: Tên tùy chỉnh cho tài khoản Dropbox sử dụng.
    - **Mã truy cập (Access Token)**: Nhập mã truy cập của Dropbox để kết nối.
    - **Đường dẫn thư mục**: Tên thư mục trong Dropbox để lưu trữ các file (có thể tùy chỉnh).
    - **Kích hoạt**: Kích hoạt tùy chọn này để cho phép đẩy file lên Dropbox.
    - **Đường dẫn liên kết**: Đường dẫn đến thư mục trong Dropbox nơi file sẽ được lưu trữ.

---

## Bước 3: Cấu Hình Tìm Kiếm Theo Nội Dung File

1. Truy cập vào **Tài liệu -> Cấu hình -> Cài đặt** để thiết lập tính năng tìm kiếm file theo nội dung.
2. Cung cấp **URL** cho dịch vụ tìm kiếm nội dung file. Ví dụ: `http://127.0.0.1:5005`.

---

Sau khi hoàn tất các bước trên, bạn đã sẵn sàng sử dụng **Saas Documents** để lưu trữ trên Dropbox và tìm kiếm nội dung tài liệu.
